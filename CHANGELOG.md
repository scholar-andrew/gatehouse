# Changes

What changed in each version of the pack, newest first. Generated by `tools/build_pack.py` from
`source/changelog.json`; players see the same notes in the pop-up before the game starts after an update.

## 1.6.0 (2026-11-14)

- A pop-up like this one now shows before the game starts: what's new after an update, or that you're up to date (that one closes itself after 5 seconds).
- Turn either pop-up off in Mods > October Journey (Update pop-up, No-update pop-up).

## 1.5.0 (2026-11-14)

- Every mod that isn't a library can now be switched off in Mods > October Journey. All are on by default, except the two nearby-chest mods.
- New installs hide Inventory Profiles Next's Auto Refill arrows on the hotbar (change it in that mod's settings).

## 1.4.0 (2026-11-14)

- Stack to Nearby Chests and Nearby Chest Crafting are off by default. Switch them on in Mods > October Journey.

## 1.3.6 (2026-11-14)

- Fixed the first launch on a new install sometimes starting without the pack's mods.

## 1.3.5 (2026-11-14)

- If the mods can't be installed on the first launch, it stops and asks you to press Play again instead of starting plain Minecraft.

## 1.3.4 (2026-11-14)

- Setup and the uninstaller offer a quick install or a choice of each part, and where it goes.

## 1.3.3 (2026-11-14)

- Chat moves up to fit Steam's keyboard on any screen size.

## 1.3.2 (2026-11-14)

- With a Steam controller, Steam + X opens Steam's keyboard and chat moves up above it.

## 1.3.1 (2026-11-14)

- Typing with Steam's keyboard works while using a Steam controller.

## 1.3.0 (2026-11-14)

- Steam controllers use Steam's keyboard; other controllers keep Controlify's own keyboard.

## 1.2.2 (2026-11-14)

- The update that runs before each launch keeps itself up to date.

## 1.2.1 (2026-11-14)

- The October Journey server stays in your multiplayer list with the right address.

## 1.2.0 (2026-11-14)

- Steam library art and the Steam Deck controller layout are kept up to date.

## 1.1.0 (2026-11-14)

- Controller support (Controlify) on every device, with fixes for Steam controllers and the Steam Deck.

## 1.0.0 (2026-11-14)

- The first October Journey pack.
