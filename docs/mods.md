## Mods made or patched for this pack

- **chatlift-1.1.3.jar**: Steam keyboard handling: lifts chat above Steam's keyboard, keeps Controlify's own keyboard for non-Steam controllers, lets Steam's keyboard type (Controlify mixed input). Made for this pack.
- **handofffix-1.0.0.jar**: Fixes Controlify losing the Steam Deck's controls after another controller is unplugged. Made for this pack.
- **octoberjourney-1.2.2.jar**: Gatehouse Settings: the pack's settings in Mod Menu (switch the pack's mods and the launcher's windows on and off). Part of Gatehouse, the launcher these packs use.
- **RoughlyEnoughItems-26.3.824-brewingfix.1.jar**: Roughly Enough Items 26.3.824 with one class patched so brewing recipes load on the server. Also installed on the server.
